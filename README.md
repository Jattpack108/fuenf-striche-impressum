# Impressum Fünf Striche

Impressum für die Profile von Fünf Striche auf Instagram und Pinterest, ausgeliefert über GitHub Pages.

## Ausfüllen

In `index.md` die vier Platzhalter in eckigen Klammern ersetzen: Name (zweimal), Straße und Hausnummer, PLZ und Ort, E-Mail. Am Telefon: GitHub-App oder github.com › Datei `index.md` › Stift › ändern › „Commit changes“. Nach etwa einer Minute ist die Seite aktuell.

Die Seite trägt `noindex`: Suchmaschinen sollen sie nicht aufnehmen, erreichbar bleibt sie über den Link.
