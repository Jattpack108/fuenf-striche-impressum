# Impressum Fünf Striche

Impressum für die Profile von Fünf Striche auf Instagram und Pinterest, ausgeliefert über GitHub Pages (eine statische Seite, `index.html`).

Die Pflichtangaben stehen auf der Seite, nicht im Quelltext als Klartext: Der Block wird beim Laden aus einer kodierten Zeichenfolge eingesetzt, ohne JavaScript zeigt die Seite ihn als Bild. Grund: Die Angaben sollen für Besucher der Profile erreichbar sein, aber nicht über Suchmaschinen oder die GitHub-Suche gefunden werden. Dazu `noindex`, `robots.txt` (alles gesperrt) und `nofollow`.

Ändern: nicht von Hand in `index.html`; eine Claude-Session baut den Block neu (Text im Chat nennen). Nach dem Commit ist die Seite nach etwa einer Minute aktuell.
