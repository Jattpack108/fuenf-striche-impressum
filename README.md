Impressum für die Profile von Fünf Striche auf Instagram und Pinterest, ausgeliefert über GitHub Pages.

## Ausfüllen

Name und Anschrift stehen seit 27.10.2026 drin. Offen ist nur noch die E-Mail: in `index.md` den Platzhalter `[E-Mail-Adresse]` ersetzen. Am Telefon: GitHub-App oder github.com › Datei `index.md` › Stift › ändern › „Commit changes“. Nach etwa einer Minute ist die Seite aktuell.

Die Seite trägt `noindex` (dazu `noarchive`, `nosnippet`, `noimageindex`): Suchmaschinen sollen sie nicht aufnehmen, erreichbar bleibt sie über den Link.
